# ASX Weekly Market Report

每周自动生成并发送澳洲股市（ASX）周报，同时发布到 GitHub Pages。  
The project generates a weekly ASX market report, emails it, and archives it on GitHub Pages.

## 当前架构 | Current Architecture

项目现在使用**确定性规则引擎**，不再依赖 z.ai / GLM 或其他 LLM 来生成报告正文。  
The report body is now produced by a **deterministic rules engine** instead of an LLM.

### Pipeline

1. **抓取市场数据 | Fetch market data**
   - Yahoo Finance quote page scraping for ASX 200 and key stocks
   - Yahoo Finance chart API for recent index history
   - Market news headline scraping from ABC / AFR
2. **规则打分 | Score with rules**
   - 市场概况：按周收益、月收益、近10日波动率、成交量变化分类
   - 个股分析：按涨跌幅、新闻命中次数、成交量相对强弱排序
   - 投资日历：按固定宏观事件规则生成未来 1-2 周日历
   - 风险提示：按波动率、放量下跌、临近事件等条件触发
3. **模板渲染 | Render templates**
   - 生成与原有结构兼容的 Markdown 文本
   - 转换为 HTML / TXT 输出
4. **输出 | Output**
   - 保存到本地或 `docs/`
   - 可选发送邮件
   - 更新归档索引

## 规则说明 | Scoring Rules

### 市场概况 | Market overview

- **risk-on**: 周收益 ≥ 1.5%，月收益 ≥ 3%，且近 5 日均量相对前一阶段放大 ≥ 5%
- **risk-off**: 周收益 ≤ -1.5%，月收益 ≤ -3%，且近 5 日均量放大 ≥ 5%
- **区间震荡**: 周收益绝对值 < 1%，月收益绝对值 < 2%，波动率 < 0.8%
- **高波动轮动**: 波动率 ≥ 1.4% 或成交量变化绝对值 ≥ 15%
- 其余情况归类为 **结构分化**

### 个股分析 | Stock analysis

重点股按以下确定性分数排序：

- `2 × |日涨跌幅|`
- `1.5 × 新闻关键词命中次数`
- `+1` 成交量处于样本上半区
- `+1` 与大盘方向相反（逆势强/弱）

默认从核心样本池中选 3 只：
`BHP, CBA, CSL, NAB, WBC, ANZ, WES, WOW, RIO, FMG, MQG, TLS, WDS, ALL, QAN`

### 投资日历 | Investment calendar

未来两周事件由固定规则生成，包括：

- RBA 利率决议（每月第一个周二）
- NAB 商业景气调查（每月第二个周二）
- Westpac 消费者信心指数（每月第二个周三）
- 澳洲就业数据（每月第三个周四）
- RBA 会议纪要（每月第三个周二）
- 澳洲月度 CPI 指标（每月最后一个周三）
- 财报/经营更新窗口（1/2/4/7/10 月额外提示）

### 风险提示 | Risk alerts

以下条件命中即触发：

- 近 10 日波动率 ≥ 1.4%
- 指数近 5 日跌幅 ≤ -1.5% 且成交量同步放大
- 未来几天有高影响宏观事件

## 配置 | Configuration

复制 `.env.example` 为 `.env`：

```bash
cp .env.example .env
```

支持的环境变量：

```bash
GMAIL_ADDRESS=your@gmail.com
GMAIL_APP_PASSWORD=your_app_password
RECIPIENT_EMAIL=

# optional
OUTPUT_DIR=/path/to/output
```

> `GMAIL_*` 为可选项。未配置时，脚本仍会生成 HTML / TXT / archive，只是跳过邮件发送。  
> `GMAIL_*` is optional. Without it, the report still generates successfully and email is skipped.

## 运行方式 | Running

### 本地运行 | Local

```bash
chmod +x setup.sh
./setup.sh
./run_report.sh
```

也可直接运行：

```bash
python3 asx_weekly_reporter.py
```

### GitHub Actions

Workflow 位于 `.github/workflows/asx-weekly-report.yml`，默认每周六早上 8 点（AEST）运行。

推荐配置以下 secrets：

- `GMAIL_ADDRESS`
- `GMAIL_APP_PASSWORD`
- `RECIPIENT_EMAIL`

如果未配置邮件 secrets，workflow 仍可生成 `docs/` 报告。

## 输出 | Output

- HTML 报告
- TXT 摘要
- `docs/index.html` 历史归档页

## 扩展点 | Extension Points

如需继续增强 deterministic pipeline，可直接扩展：

- `EVENT_RULES`：增加更多固定事件
- `STOCK_KEYWORDS`：增加个股/板块主题关键词
- `_classify_market_regime()`：调整市场阈值
- `_rank_focus_stocks()`：调整个股打分规则
- `_generate_*()`：替换模板文案
